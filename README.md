# Memory YO

Jeu de mémoire simple en HTML/CSS/JS.

## Installation

1. Placez vos images de bouteilles dans le dossier `images/`.
2. Renommez-les selon les goûts ou mettez à jour `script.js`.
3. Ouvrez `index.html` dans un navigateur.

## Personnalisation

- Ajoutez d'autres goûts dans le tableau `tastes` de `script.js`.
- Ajustez le nombre de cartes en changeant le menu de difficulté.

Règles : Memory YO

Le but du jeu est de retrouver toutes les paires de cartes identiques en mémorisant leur position.

  • Clique sur une carte pour la retourner.
  • Clique sur une deuxième carte pour essayer de former une paire.
  • Si les deux cartes sont identiques, elles restent visibles.
  • Si elles sont différentes, elles se retournent automatiquement.
  • Termine toutes les paires pour gagner la partie.
  • En cas de victoire, tu participes au tirage au sort YOYO pour gagner une PS5.

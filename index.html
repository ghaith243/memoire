Règles : Memory YO

Objectif : Retrouver toutes les paires de cartes identiques en un minimum de coups.

  • Cliquez sur une carte pour la retourner.
  • Cliquez sur une deuxième carte pour tenter de former une paire.
  • Si les cartes sont identiques, elles restent visibles.
  • Si elles sont différentes, elles se retournent.
  • Mémorisez les positions pour gagner rapidement.

Niveaux :

  • Facile : 12 cartes (6 paires)
  • Moyen : 20 cartes (10 paires)
  • Difficile : 32 cartes (16 paires)

Astuce : développez une stratégie de mémorisation systématique !
